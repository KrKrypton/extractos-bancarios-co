# Ejemplos de demostración

Archivos de texto **100 % ficticios**: nombres, cuentas y montos inventados. No corresponden a personas ni productos reales.

```bash
.venv/bin/python scripts/ejecutar_demo.py
```

Esto copia los ejemplos a `salida/texto/demo/`, genera JSON y un mini maestro en `salida/consolidado/`.
